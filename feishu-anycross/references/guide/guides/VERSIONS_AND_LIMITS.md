# 版本差异与运行限制

资料日期：2026-09-21。下列数值来自采集时的官方文档；“最新版本”是文档页的标注，不代表模板、已有节点或当前租户已采用该版本。逐组件版本快照见 [总索引](../INDEX.md)。

## 1. 先区分五种版本

| 对象 | 含义 | 配置时如何确认 |
|---|---|---|
| 连接器版本 | 决定可选操作和字段契约 | 在实际节点面板查看；再对照该版本文档 |
| 连接器修订编号 | 两位可见版本号之外，平台发布时自动添加的第三位编号 | 官方说明修订版可以无感更新；两位号不变不等于实现冻结 |
| 应用凭证版本 | 新版／旧版凭证协议 | 按具体操作的适配提示选择，创建后不能修改版本 |
| 工作流编辑稿与发布配置 | 当前编辑内容与对外运行配置 | 查看工作流当前状态，不把保存当成发布 |
| 卡片／外部 API 版本 | 业务系统自己的发布版本或接口版本 | 与连接器版本分开记录，例如消息卡片发布版本 |

连接器两位号任一位递增，属于新版本，已有节点需手动切换。前两位不变的修订版可无感升级。若发布范围删除了操作，开发工具要求发布新版本，不能通过修订版删除。

来源：[连接器版本管理](../reference/platform-connector-version-control.md)、[凭证升级说明](../reference/faq-connector_upgrade_instructions.md)。

## 2. 已有证据的差异

| 组件／能力 | 版本或场景 | 已知差异与操作影响 |
|---|---|---|
| 动态脚本 | 1.2 及以下与之后版本 | 旧版入参格式不同；迁移时按实际 Input 表单核对，不直接照抄新版本截图 |
| 动态脚本 | 1.5 及以下 → 2.0 及以上 | 旧版仅执行 `handler` 内函数；新版可执行与 `handler` 同级声明的函数 |
| 动态脚本 | 2.0 及以上 | 限制 `RegExp.$1` 至 `$9`；应使用正则执行结果数组 |
| 动态脚本 | 2.0 及以上 | 文档列出 `atob`、`btoa`、`TextEncoder`、`TextDecoder`、`URL`、`URLSearchParams`、`anycross.CryptoJS`；不因此获得网络 IO 能力 |
| 同步网址触发回调 | 早期 → 1.2 → 1.3 及以上 | `flow_key` 早期手填；1.2 有默认值且可编辑；1.3 起隐藏并由系统填充 |
| HTTP Client | 2.0 | 正文有字段标为“已废弃，2.0 版本不再支持”；迁移应逐项核对响应解析和编码配置，不能按旧字段机械填写 |
| 金蝶云星空 | 1.6 及以上 | 业务对象表单 ID 已预设默认值并隐藏；不能因为金蝶 API 文档标为必填就认定节点缺字段 |
| 飞书通讯录凭证 | 官方示例：2.1 及以下／2.2 及以上 | 升级说明将旧版与新版凭证分别对应低版本和高版本；这不是全部连接器通用分界线 |
| 飞书通讯录事件／动作 | 官方历史示例：2.7 | 事件节点和普通动作的凭证升级进度曾不同；相同连接器版本也不能保证两者凭证适配一致 |
| 飞书消息／飞书群组 | 当前目录与旧正文 | 群组已单独列为连接器，消息页仍保留创建群旧案例；选操作时以当前目录与实际版本为准 |
| 消息卡片助手 | 更新简报记录 | 切换卡片版本或刷新变量列表可保留上次变量值；简报没有提供完整逐版字段差异表 |
| 模板与公开组件页 | 本次只读预览 | HelloWorld 中卡片助手 1.2、飞书消息 2.12；消息公开页标注 2.18。只能确认版本不同，不能由此推断所有行为差异 |

具体原文与参数在 [逐组件手册](../manuals/README.md)。公开文档没有提供全部 124 个组件的历史版本包；没有明确证据的历史差异标为未知，不把最新文档反推为旧版能力。

## 3. 工作流级限制

| 层级 | 官方限制 | 计算或失败行为 |
|---|---:|---|
| 画布节点 | 200 | 连接器和触发器都计入；超出会阻止调试和发布 |
| 画布嵌套 | 10 层 | 分支、循环、While 内的子节点增加层级 |
| 一次调试执行节点 | 10,000 | 到达上限后不运行新节点，日志为运行终止 |
| 一次调试时长 | 4 小时 | 到达上限后不再运行新节点 |
| 发布后一次执行节点 | 40,000 | 包含子流程执行节点；循环按实际执行次数累计 |
| 发布后一次运行时长 | 4 小时 | 到达上限后不再运行新节点 |
| 租户同时运行工作流 | 100 | 已在运行的继续；新触发的首节点失败并终止 |
| 单节点入参＋出参 | 4M | 合计计算，超限节点失败；原文使用 `4M`，不自行换算成精确字节数 |
| 普通单节点最长运行 | 60 秒 | 当前使用限制页的口径；专用组件还可能有更短限制 |
| 运行日志保存 | 30 天以内、200 MB 以内 | 来自日志文档，不能用作长期审计存档保证 |

触发器计入执行节点；未走到的分支不计入；循环执行 N 次、每次 X 个节点，相关执行量为 N×X。画布 200 个节点与运行 40,000 个节点是不同维度。

来源：[使用限制](../reference/faq-limits.md)、[运行日志](../reference/platform-view-runtime-logs.md)。旧 [更新简报](../reference/updates-release-notes.md) 曾写 30 秒，不能代替当前限制页的 60 秒；动态脚本另有 1 秒限制。

## 4. 组件级限制

| 组件 | 官方限制 | 配置含义 |
|---|---|---|
| 分支／广播 | 最多 20 分支，每支最多 10 条件 | 互斥分支有默认路径；广播没有 |
| 并行循环 | 列表最多 1,000 项，超出仅处理前 1,000 项 | 先分批，不能假定溢出自动续跑 |
| 并行循环 `maxSize` | 最大 10 | 原文解释为“每秒启动线程数”；不能直接当成持续在途并发数 |
| While | 最大循环次数 1,000 | 模板中的 100 是配置值；业务还要有明确结束条件 |
| 延迟 | 最长 3 秒 | 不能用它实现小时级等待 |
| 子流程 | 最多 3 层嵌套 | 另受主流程执行总数及运行时间约束 |
| 同步网址触发器 | 等待 1–60,000 毫秒 | 请求超时后后台流程可能继续 |
| Webhook Body | JSON 小于 2M；Text 小于 4M | 以对应触发器参数定义为准 |
| 同步回调 | 入参整体不超过 256KB | 超出可能截断并导致回调节点失败 |
| 动态脚本 | 1 秒，同步计算 | 官方建议入出参合计不超过 4 MB；不支持 HTTP／RPC IO；系统时区 UTC |
| HTTP 文件上传 | 文档标注 40M | 对应平台文件类型，不代表普通字符串可突破节点 4M 限制 |
| 设置变量 | 最多 30 组；名称最长 50 字符 | 数字、字母、下划线，不能数字开头 |
| 普通变量值 | 单个 4KB | array／object 另按下一行 |
| 列表／对象变量值 | 单个 1MB，最多 5,000 元素／属性 | 不因循环次数少就忽略容量 |
| 并行场景变量 | 单次运行含子流程，变量存储总上限 1MB | 仅在“在并行场景下使用变量”选择“是”的适用场景下解释此限制 |
| 数据存储集合 | 项目最多 99 个自定义集合，每集合最多 20,000 键值对 | 属于持久存储容量 |
| 数据存储单值 | 1MB；列表／对象最多 5,000 元素／属性 | 键最长 100 字符 |
| 数据存储嵌套 | 表单 3 层；表达式连线数据 5 层 | 不同输入方式的层级限制不同 |
| 获取数据存储所有键 | 单页条数不超过 10,000，返回大小另受 2M 限制 | 可能未达到请求条数就分页；按返回游标判断 |
| CSV 解析 ID | 同一工作流当次运行内有效 | 不能跨项目、工作流或传给子流程使用 |

这些限制来自对应组件正文，入口在 [逻辑](../INDEX.md#logic)、[助手](../INDEX.md#helpers)、[触发器](../INDEX.md#triggers)。业务连接器还受外部 API 的分页、频率、权限和资源限制；本资料没有把外部接口限额统一成平台限额。

## 5. 将来切换版本时记录什么

在用户授权的专属项目中，记录节点实例 ID、操作、当前版本、凭证版本及受影响字段；切换后只核对变更字段与相关引用，并执行一次代表性入口验证。涉及历史兼容性但资料没有答案时，应先补充实际观察，再更新手册。不能在其他项目上试升级，也不默认重跑全量业务数据。
