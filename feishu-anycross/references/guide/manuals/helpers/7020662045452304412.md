# HTTP Client 操作手册

[组件索引](../../INDEX.md#helpers) · [操作索引](../../OPERATIONS.md#helpers-7020662045452304412) · [官方资料](https://anycross.feishu.cn/documentation/connector/helper/7020662045452304412)

快照日期：2026-09-21。文档标注最新版本：**2.2**。本页含 **5** 个事件／操作名称条目。

## 1. 使用要点

按请求方法、Body 类型、解析器、编码和成功状态码逐项配置。2xx 不等于业务成功；平台文件字段的 40M 不能推广到普通节点文本。

## 2. 配置与连接步骤

1. 在授权项目中搜索组件全名 **HTTP Client**，核对图标与组件名称。

2. 从下表选择具体操作；事件作为工作流入口，普通动作放到目标路径，逻辑组件需确认分支／循环体边界。

3. 核对节点实际版本；需要认证的操作选择适用凭证，并按链接的官方步骤核对业务侧前置条件。

4. 在入参中逐项确认类型、必填、默认值和“未输入”状态；从 `$` 胶囊选择器或 snake 连线引用真实上游字段。

5. 分别检查流程箭头与数据引用。下游引用要对应实际操作出参；一次运行验证后才能把动态字段结构列为已验证。

具体拖拽、落点、胶囊、错误处理与日志步骤见 [Computer Use 手册](../../guides/COMPUTER_USE.md)。这些是后续操作步骤，本次没有执行。
