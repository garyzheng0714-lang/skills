# 步骤一：创建并配置自建应用

> 来源：飞书开放平台官方文档。原文保真存档。

在飞书开放平台中开发网页应用时，需先创建企业自建应用并添加网页应用能力。

## 操作步骤

1. 登录[飞书开发者后台](https://open.feishu.cn/app)。
2. 在开发者后台首页，单击 **创建企业自建应用**，填写应用名称、描述以及图标信息，然后单击 **创建**。
3. 在应用详情页，进入 **应用能力** > **添加应用能力** 页面。
4. 添加 **网页应用** 能力。
5. （可选）进入 **应用能力** > **网页应用** 页面，配置网页应用主页地址。
   - 已开发完成可直接填公网地址。
   - 未开发可暂留空，或在开发调试阶段用 ngrok 反向代理工具。
   - 若公司网络安全策略不允许使用反向代理，可暂时本地调试填 `http://127.0.0.1:3000`。
6. （可选）配置在飞书客户端内打开桌面端主页后，跳转其他新页面的打开方式。

## 桌面端主页打开方式（V7.4+）

V7.4 以下：默认在飞书内打开，`window.open` 或 `<a target="_blank">` 一律跳浏览器。

V7.4 及以上：可选「**在飞书内新标签页打开**」或「**在浏览器中打开**」。

注意：**桌面端主页默认在飞书客户端内打开**。如需配置主页在浏览器中打开，需要在 URL 中拼接 `lk_jump_to_browser=true` 参数（见 `web-meta/jump-to-browser.md`）。

### 「在飞书内新标签页打开」的特性

- 标签页中显示的名称是**网页本身定义的名称**，不再是应用名称。
- 用户固定标签页到主导航，下次重新打开会**直接进入标签页对应的页面**，而不再是从主页开始。**任意子页面都需要兼容用户登录和网页鉴权**。

### 「在浏览器中打开」的特性

- 与 V7.4 以下版本保持一致。
- 标签页固定到主导航，下次会**重新进入主页**。

## 常见问题

### 配置桌面端主页打开方式的影响范围
1. 仅影响 `window.open` 和 `<a target="_blank">`，**不影响** `openSchema API`。
2. 通过 `window.open` 或 `<a>` 打开普通网页 AppLink → 该普通网页中跳转新页面不再受网页应用打开方式控制，与飞书会话中打开该链接的方式一致。
3. **独立窗口方式**打开的网页应用跳转**不受**该打开方式影响，仍跳浏览器。

### 鉴权指向其他应用时如何打开
应用 A 打开的新页面做了鉴权指向应用 B → 该新页面中打开页面跳转浏览器还是飞书内打开**受应用 B 控制**。

### 配置后应用首页仍在飞书内打开
V7.7+ 在桌面端主页 URL 后拼接 `lk_jump_to_browser=true`，可让首页直接跳浏览器打开。示例：`https://open.feishu.cn/?lk_jump_to_browser=true`。
