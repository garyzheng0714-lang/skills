# 步骤四：发布与使用应用

> 来源：飞书开放平台官方文档。原文保真存档。

完成应用开发后，需正式发布。已发布的应用可通过飞书客户端访问使用。

## 发布应用

1. 登录[开发者后台](https://open.feishu.cn/app)。
2. 找到并进入需要发布的自建应用详情页。
3. 在左侧导航栏，选择 **应用发布** > **版本管理与发布**。
4. 在页面右上角，点击 **创建版本**。
5. 在版本详情页，依次配置版本号、应用能力、可用性状态等，然后点击保存。
   - **应用版本号**：自定义，格式示例 `1.0.0`。
   - **默认能力**：设置移动端和 PC 端的默认应用能力，此处需选择「网页应用」。
   - **更新说明**：展示在更新日志中。
   - **可用范围**：自定义当前应用的可用范围，仅可用范围内的用户可搜索并使用。
   - **申请理由**：帮助审核人员了解附加信息。
6. 点击 **申请线上发布**。

等待审核通过后，即成功发布应用。

## 使用应用

### 方式一：移动端工作台搜索

打开飞书移动端 → **工作台** → 搜索并打开应用。

### 方式二：开发者工具二维码

1. 运行示例项目，获取临时访问地址。
2. 同一局域网中打开飞书开发者工具，添加网页项目。
3. 项目中添加临时访问地址。
4. 打开预览功能内提供的移动端二维码。
5. 使用飞书移动端扫一扫扫描，使用应用。

### 方式三：桌面端工作台搜索

打开飞书桌面端 → **工作台** → 搜索并打开应用。

## 调试

- 页面右下角的 `vConsole` 进行简单本地调试。
- 开放平台「小程序/网页应用在线调试工具」：实时调试运行中的小程序和网页应用。
  - 支持范围：Android + 飞书 V5.1+。
