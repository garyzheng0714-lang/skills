# 网页应用开发指南概述

> 来源：飞书开放平台官方文档（用户 2026-05-21 提供）。本文件原文保真存档，作为飞书网页应用接入的真相来源。

## 基本概念

| 属性 | 类型 |
|---|---|
| 鉴权 | 当你调用开放平台客户端 API（JSAPI）时，飞书为了数据安全，需要先验证网页应用有权限访问的 JSAPI 范围，该过程称为鉴权。 |
| 免登 | 免登是指飞书用户在客户端内进入网页应用后，无需输入飞书用户名和密码，网页应用便可自动获取当前用户身份，进而登录系统的流程。 |
| JSSDK | 飞书客户端 JSSDK 是飞书面向客户端网页开发者（接入方）提供的网页开发工具包，仅可用在飞书客户端内。 |
| access_token | 带有授权的飞书开放平台访问凭证。3 种类型：`app_access_token`（应用）、`tenant_access_token`（租户）、`user_access_token`（用户）。 |
| jsapi_ticket | 代表网页应用调用飞书 JSAPI 的临时凭证，是实现鉴权校验的重要数据。鉴权方式：对比接入方服务端依据 `jsapi_ticket` 等数据生成的签名，与认证中心生成的签名是否相等。 |
| 签名 | 用于 JSSDK 权限验证的密文。对 `jsapi_ticket`、网页 URL 等参数拼接成 `verifyStr`，用 sha1 加密得到的密文就是签名 `signature`。 |
| URL | 标准格式：`[Schema]://[Domain]:[Port]/[Path][文件名]?[query]#[片段 ID]`。 |

## 角色说明

### 接入方
- **接入方前端**：JavaScript / HTML 编写，负责与用户交互。
- **接入方服务端**：负责存储数据、处理业务逻辑、响应前端请求。
- **开发者后台**：[飞书开放平台应用创建与配置后台](https://open.feishu.cn/app/)。

### 飞书
- **飞书客户端**：承载网页应用的客户端，可支持调用手机系统功能和飞书客户端功能（扫一扫、云文档等）。
- **认证中心**：负责认证网页应用身份和权限的服务端。
