# 应用角标功能开发指南

> 来源：飞书开放平台官方文档。原文保真存档。

## 功能介绍

应用角标是应用（小程序/网页应用）的一种信息通知能力，类似 IM 的未读消息标识。应用图标右上角展示红色数字角标。

**展示范围**：
- 1~999：显示为红色数字
- > 999：显示为红点

## 展示位置（按工作台类型）

| 工作台类型 | 支持版本 | 表现 |
|---|---|---|
| 定制工作台 | V5.15 | 应用图标右上角；主导航工作台右上角的数字 = 常用应用角标和 + 应用列表角标去重和 |
| 网页嵌入工作台 | V5.18 | 仅主导航工作台右上角展示，数字是网页内部应用角标去重和（网页内部角标由用户自行实现） |
| 默认工作台 | 无版本要求 | 应用图标右上角（我的常用 / 分组应用展示，全部应用不展示）；主导航工作台右上角的数字 = 我的常用 + 分组应用去重和 |

## 飞书客户端中开关

应用接入后，用户首次进入会查看到「开启角标的权限申请弹窗」。后续可在应用右上角 **···** → **关于** 页面开启或关闭。

**任意端开关 → 同步到所有客户端**。

## 使用前提

- **自飞书 3.42.0 版本开始支持**。
- 应用必须开启小程序或网页功能。

## 使用流程

### 步骤一：应用鉴权
- 小程序：登录小程序
- 网页：H5JSSDK 鉴权

### 步骤二：申请用户授权

应用角标需要用户授权后才能使用。

```js
const SCOPE_BADGE = "scope.appBadge"

tt.getSetting({
  success: (res) => {
    if (!res?.authSetting?.hasOwnProperty(SCOPE_BADGE)) {
      // 首次：请求授权
      tt.authorize({
        scope: SCOPE_BADGE,
        success(res) { /* badgeAuthed = true */ },
        fail(res) { /* badgeAuthed = false */ },
      })
      return
    }
    if (!res.authSetting[SCOPE_BADGE]) {
      // 用户拒绝过：打开设置页引导授权
      tt.openSetting({
        success(res) { /* badgeAuthed = res.authSetting[SCOPE_BADGE] */ },
      })
    }
  },
})
```

### 步骤三：设置应用角标数字

#### 服务端设置（基础，必须）

通过服务端调用「更新应用红点」接口更新角标数字。**不能跳过服务端设置直接用客户端设置**。

#### 客户端设置（可选）

当用户在当前设备应用内进行了会造成角标变化的操作时（例如完成审批），可通过 `tt.updateBadge` 快速更新当前设备的角标数，优化网络延时造成的更新不及时。

```js
tt.request({
  url: URL_BADGE_SERVICE,
  // ...
  success(res) {
    tt.updateBadge({
      badgeNum: badgeItem.badgeNum,
      success(res) { /* ... */ },
    })
  },
})
```

⚠️ **客户端设置注意**：
1. 前提是当前设备已有 Badge 数据（**至少先通过服务端设置过一次**）。
2. 只能操作当前设备的 Badge 数据，**更新多端 Badge 用服务端设置**。
3. 客户端设置的 Badge 数据会**被服务端设置覆盖**，因此用客户端设置时需同步进行服务端设置。

## 注意事项（设计层面）

- **通过友好方式征询授权**：先在应用内告知用户功能价值，再申请授权。
- **提供清晰的承接信息**：进入应用能快速找到与角标数字对应的信息。
- **提供明确的消除方式**：用户完成消除操作时及时更新角标数字。
- **合理使用**：用户注意力有限，评估提醒的信息是否重要、必须关注。

## Q&A

### `tt.updateBadge` 没成功更新角标

A：客户端设置的前提是当前设备已有 Badge 数据，**至少先通过服务端设置过一次**。

### 固定在主导航栏的网页应用角标数字不对（7.10+）

A：网页应用桌面端配置为「在飞书内新标签页打开」时，**不会对主导航栏的角标进行更新**（工作台内不受影响）。

### 网页应用调用接口失败

A：先做鉴权 + 确认 JS-SDK 版本满足要求。

### 应用角标没在工作台展示

需要同时满足 3 个条件：
1. 用户开启了应用角标授权（应用「关于」页可查）。
2. 通过服务端设置过应用角标数字且当前数字不为 0。
3. 当前应用被用户添加到了工作台「我的（常用）应用」或「应用分组」。

### 网页应用 `tt.getSetting` 取不到 `scope.appBadge` 数据

**原因**：JSSDK ready 和 `tt.getSetting` 存在时序问题。

**处理**：`window.h5sdk.ready` 后**不要立刻**调接口，**设置 1000ms 延时**再调 `tt.getSetting`、`tt.authorize`。
