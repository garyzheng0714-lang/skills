## 一、快速开始(5 分钟上手)

### 1. 打开模板

1. 在任意电脑上**双击** `FBIF2026议程模板.html`
2. 自动用默认浏览器打开(**推荐 Chrome**,其他浏览器可能排版有差异)
3. 页面加载完成后,右上角会显示总页数和缩放统计

### 2. 导出 PDF

1. 点击右上角 **"打印 / 导出全部 PDF"** 按钮(或按 `Ctrl/Cmd + P`)
2. 在打印对话框中:
   - **目标**:选"另存为 PDF"
   - **版式**:选**横向**
   - **纸张尺寸**:A4
   - **边距**:选**无**(或"默认")
   - **选项**:勾选**"背景图形"**(非常重要,不然颜色会丢失)
3. 点击"保存",选保存位置
4. 得到一份 33 页的完整议程 PDF

### 3. 修改内容

用任意文本编辑器打开 HTML 文件(**推荐 VS Code**,自带语法高亮更容易找):
- Windows:右键 HTML 文件 → "打开方式" → VS Code
- Mac:同上

修改完**保存**(Ctrl/Cmd + S),回到 Chrome **刷新**(F5),看效果。

## 三、议程内容修改(最常用)

### 3.1 找到 PAGES 数据位置

在 HTML 中搜索 `const PAGES = [`,这是所有议程数据的起点。

PAGES 是一个数组,包含 15 个议程页对象,顺序是:
```
[0] 乳品 4.27      [1] 乳品 4.28
[2] 饮料 4.27      [3] 饮料 4.28
[4] 零食 4.27
[5] 功能性食品 4.28
[6] 首席选品官 4.27 [7] 首席选品官 4.28
[8] 包装 4.27      [9] 包装 4.28
[10] 营销 4.27     [11] 营销 4.28
[12] 产品开发 4.27 [13] 产品开发 4.28
[14] 全体大会 4.29
```

### 3.2 每个议程页的数据结构

```javascript
{
  forumKey: 'rupin',           // 论坛标识(不要改)
  date: '4月27日 (第一天)',     // 顶部日期
  scaleOverride: null,         // 手动缩放(null=自动)
  columns: [                   // 两栏,最多 2 个
    {
      sectionLabel: '领军观察', // 左栏标题,14pt
      items: [
        { time: '09:35', title: '主席致辞', simple: true },
        { time: '09:40',
          title: '话题标题',
          desc: '话题描述...',
          guests: [{ name: '嘉宾姓名', title: '职位', company: '公司' }] },
        ...
      ]
    },
    { sectionLabel: '创新引擎', items: [...] }  // 右栏
  ]
}
```

### 3.3 常见改动

#### 改话题时间
搜索原时间(如 `09:40`),直接改成新时间(如 `09:45`)。

#### 改话题标题和描述
搜索话题标题的一部分(比如"穿越周期"),找到后改 `title` 和 `desc` 字段。

#### 改单个嘉宾
搜索嘉宾姓名,修改 `name`、`title`、`company` 字段。

#### 增加一位嘉宾
在 `guests: [...]` 数组里加一个对象,注意**每个对象之间用逗号分隔**:
```javascript
guests: [
  { name: '张三', title: 'CEO', company: 'A公司' },
  { name: '李四', title: 'CTO', company: 'B公司' }   // ← 新增
]
```

#### 删除一个话题
找到对应的 `{ time: '...', title: '...', ... }` 整个对象,连同**前面或后面的逗号**一起删除。

#### 新增一个话题
在 `items: [...]` 里加一个新对象:
```javascript
{ time: '14:30',
  title: '新话题标题',
  desc: '新话题描述',
  guests: [{ name: '嘉宾', title: '职位', company: '公司' }] },
```

### 3.4 特殊标签(tag)

话题标题前可以加小标签,比如"现场访谈"、"访谈与品鉴":
```javascript
{ time: '10:40', tag: '现场访谈',
  title: '穿越周期:从培育到重塑增长曲线',
  ... }
```

### 3.5 多嘉宾带 prefix

当一个话题有多个嘉宾(主持、讨论),用 prefix 字段分组:
```javascript
guests: [
  { prefix: '【主持嘉宾】', name: '王航', title: '创始合伙人', company: '厚生投资' },
  { prefix: '【圆桌嘉宾】', name: '信跃升', title: '高级合伙人', company: '信宸资本' },
  { name: '张晶', title: '合伙人', company: '春华资本集团' }   // 没 prefix 的默认跟上一个分组
]
```

超过 6 人会自动两栏布局。

## 四、嘉宾名单页修改(第 2-4 页)

### 4.1 找到 GUEST_LISTS 数据

搜索 `const GUEST_LISTS = {`,下面是完整的嘉宾名单数据。

数据结构:
```javascript
const GUEST_LISTS = {
  "title": "分享嘉宾名单",   // 大标题
  "forums": [
    {
      "forumKey": "quanti",        // 论坛标识
      "name": "全体大会",          // 显示名
      "guests": [
        { "name": "侯孝海", "title": "中国区COO", "company": "正大集团" },
        ...
      ],
      "page": 2                    // ← 决定出现在哪一页 (2/3/4)
    },
    ...
  ]
};
```

### 4.2 常见改动

#### 加/删某个论坛的嘉宾
找到对应的 `forumKey`,在它的 `guests` 数组里增删。

#### 把论坛从第 2 页挪到第 3 页
找到对应论坛,改 `"page": 2` → `"page": 3`。

**当前分页:**
- page 2:全体大会 + 乳品 + 零食 + 饮料
- page 3:功能性食品 + 首席选品官 + 营销 + 产品开发
- page 4:包装创新(单独全宽)

⚠️ **注意**:每页最多装 **4 个论坛**(2×2 布局)。如果某页加多了会溢出,需要移一些到其他页。

#### 包装创新的子分组
包装创新论坛有两个子分组:
```javascript
"subgroups": [
  {
    "label": "中国包装联合会 × FBIF包装论坛 产业研讨会 参与嘉宾",
    "guests": [ ... ]
  },
  {
    "label": "研讨会 主持嘉宾",
    "guests": [ ... ]
  }
]
```

## 七、常见问题排查

### Q1:页面打开是空白的,或者排版全乱了

**原因**:HTML 文件被改坏了(多了/少了引号、逗号、括号)
**解决**:按 Ctrl/Cmd + Z 撤销最近的改动,或者从备份恢复。

### Q2:打印 PDF 后颜色丢失了,全是黑白

**原因**:打印对话框没勾选"背景图形"
**解决**:在打印对话框 → 更多设置 → 勾选**背景图形**(Chrome)或 **Print backgrounds**(英文版)

### Q3:字体看起来像宋体,很难看

**原因**:电脑没装**阿里巴巴普惠体**(免费商用字体)
**解决**:去 [阿里巴巴普惠体官网](https://fonts.alibabagroup.com/) 免费下载安装以下 3 个字重:
- Alibaba PuHuiTi 3.0 55 Regular
- Alibaba PuHuiTi 3.0 65 Medium
- Alibaba PuHuiTi 3.0 85 Bold

详见附带的 `阿里巴巴普惠体安装指南.md`。

### Q4:某一页内容太多,排版被压缩得很小

**原因**:自适应缩放触发了,那页的议程条目太多
**解决方案**:
- 精简描述文字(每条 desc 砍短一点)
- 合并两个相似话题
- 或者告诉我,我帮你调整布局

### Q5:修改 HTML 后怎么知道改对了?

**步骤**:
1. 保存 HTML 文件(Ctrl/Cmd + S)
2. 回到 Chrome,按 **F5** 刷新
3. 看页面是否正常显示
4. 如果右上角工具栏显示"总页数 33"、正常数字,说明改对了
5. 如果整个页面空白,说明改错了,按 Ctrl/Cmd + Z 撤销

### Q6:改动后想导出 PDF 和之前对比

现在改,导出一份 `FBIF2026议程_v2.pdf`,和旧版放一起对比。**建议每次大改前先备份一份 HTML**:
```
FBIF2026议程模板.html          ← 正在用的
FBIF2026议程模板_20260414.html ← 定稿备份
FBIF2026议程模板_20260420.html ← 某次改动前备份
```
