## 🚀 在新电脑上首次使用(5 分钟)

### 第 1 步:装字体

去 https://fonts.alibabagroup.com/ 下载并安装这 3 个字重:
- Alibaba PuHuiTi 3.0 · 55 Regular
- Alibaba PuHuiTi 3.0 · 65 Medium
- Alibaba PuHuiTi 3.0 · 85 Bold

Windows / Mac 都是双击安装。

### 第 2 步:确保用 Chrome

下载 https://www.google.cn/chrome/(或用 Edge 也行,内核一样)
不要用 Safari / Firefox / IE,排版会差。

### 第 3 步:打开 HTML 验证

双击 `FBIF2026议程模板.html`,等 5 秒加载,右上角应该显示:
- 总页数:**33**
- 自动缩放:**15 页**(议程页跟随内容自动缩放)
- 手动微调:**0 页**

如果看到这些数字,说明一切正常。

### 第 4 步:导出 PDF 测试

`Ctrl/Cmd + P` → 打印对话框 →
- 目标:**另存为 PDF**
- 版式:**横向**
- 纸张:**A4**
- 边距:**无**
- **必须勾选"背景图形"** ← 不勾选颜色就丢了!
- 保存

得到的 PDF 应该和 `FBIF2026议程完整预览.pdf` 视觉一致。

### 字号(完全按原议程 SOP)

- 嘉宾名单大标题:34pt
- 卡片标题:14pt
- 嘉宾信息:7pt
- 议程话题标题:11pt
- 议程描述正文:9pt
- 议程嘉宾信息:9pt
- 时间数字:14pt
- 论坛主标题:18pt

### 标点体系

**全部使用中文全角标点**:
- 逗号 `,`
- 冒号 `:`
- 问号 `?`
- 感叹号 `!`
- 分号 `;`
- 括号 `(  )`
- 引号 `"  "`
- 顿号 `、`
- 句号 `。`

**仅在以下情况保留半角**:
- 时间格式 `09:35`
- 数字小数 `8.8 元` `0.3 秒`
- 数字千位分隔 `13,000`
- 纯英文公司名 `Nitid Studio`
