## 🖥️ 新电脑上首次使用

### 步骤 1:安装阿里巴巴普惠体(非常重要)

**为什么必须装**:模板使用阿里普惠体(免费商用),如果没装,浏览器会 fallback 到系统字体(宋体/雅黑),排版会变样。

**下载地址**:https://fonts.alibabagroup.com/

**需要安装的字重**(3 个):
1. **Alibaba PuHuiTi 3.0 · 55 Regular**
2. **Alibaba PuHuiTi 3.0 · 65 Medium**
3. **Alibaba PuHuiTi 3.0 · 85 Bold**

**安装方法**:
- **Windows**:下载 `.ttf` 或 `.otf` 文件,双击 → "安装"
- **Mac**:下载 `.ttf` 或 `.otf` 文件,双击 → "安装字体"

安装完后**重启浏览器**(不是刷新页面,是整个关掉 Chrome 再打开)。

### 步骤 2:安装 Chrome 浏览器(推荐)

**为什么推荐 Chrome**:
- PDF 导出效果最接近印刷稿
- 支持 `:has()` CSS 选择器(模板用到了)
- 打印对话框最稳定

**下载地址**:https://www.google.cn/chrome/

**其他浏览器的兼容性**:
- ✅ Edge(Chromium 内核,基本一样)
- ⚠️ Safari(Mac):可以用,但 PDF 导出时字体渲染略有差异
- ❌ Firefox:不推荐,某些样式可能有问题
- ❌ IE / 老版本浏览器:完全不支持

### 步骤 3:打开模板验证

1. 双击 `FBIF2026议程模板.html`(或右键 → 打开方式 → Chrome)
2. 等待 3-5 秒(第一次加载稍慢,因为要解码 base64 图片)
3. 看右上角工具栏,应该显示:
   - **总页数:33**
   - **自动缩放:(某个数字)页**
   - **手动微调:0 页**
4. 如果显示"总页数:-" 一直不变,刷新页面(F5)再看

### 步骤 4:打印 / 导出测试

1. 按 `Ctrl + P`(Mac:`Cmd + P`)
2. 在打印对话框设置:
   - **目标**:另存为 PDF
   - **版式**:横向
   - **纸张大小**:A4
   - **边距**:无(或默认最小)
   - **缩放**:100%(或默认)
   - **选项 → 背景图形**:✅ **必须勾选**
3. 点击"保存",选位置
4. 打开导出的 PDF,应该是 33 页
5. 对比 `FBIF2026议程完整预览.pdf`,视觉应该完全一致

## 🔍 定稿版本核心参数

### 页面结构

- **总页数**:33(和原议程一致)
- **A4 横版**:297 × 210 mm
- **15 张图片**:封面、论坛结构总览、9 个论坛分隔页、3 页 Wow Food、封底
- **3 页嘉宾名单**(HTML 可编辑):
  - 第 2 页:全体大会 + 乳品 + 零食 + 饮料(4 个论坛)
  - 第 3 页:功能性食品 + 首席选品官 + 营销 + 产品开发(4 个论坛)
  - 第 4 页:包装创新(单独全宽,含 46 位嘉宾)

### 字号规格(完全按原议程 SOP)

**嘉宾名单页:**
- 大标题"分享嘉宾名单":34pt
- 卡片标题(论坛名):14pt
- 嘉宾信息(姓名/职位/公司):7pt

**议程页:**
- 论坛主标题:18pt
- 副标题:16pt
- 地址:14pt
- 时间数字:14pt
- 模块分类标签:14pt
- 话题标题:11pt(反向缩放固定)
- 描述正文:9pt
- 嘉宾信息:9pt

**底部导航:**
- 中文名:7pt
- 日期:5.5pt

### 字体系统

```
正常字体(Regular): AlibabaPuHuiTi R → 回退到 Noto Sans CJK SC → Microsoft YaHei
加粗字体(Bold):   AlibabaPuHuiTi B → 回退到 Noto Sans CJK SC Bold
中等字体(Medium): AlibabaPuHuiTi M → 回退到 NotoSansHans Medium
时间字体:         Sk-Modernist(或 AlibabaPuHuiTi Medium 作为 fallback)
```

### 自适应缩放

- **自适应下限**:0.70(最多缩到 70%)
- **自适应上限**:1.00
- **缩放策略**:整页统一缩放,两栏共用同一缩放比例
- **反向放大**:话题标题字号反向乘以 `1/ratio`,保持视觉 11pt 固定
