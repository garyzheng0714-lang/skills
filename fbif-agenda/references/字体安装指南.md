# 阿里巴巴普惠体 3.0 安装指南

本模板使用的是**阿里巴巴普惠体 3.0**,和原 FBIF 议程 PDF 是同一款字体。

## 两种使用方式

### 方式 1:联网使用(无需安装)

模板已经内置了 CDN 字体引入。**只要电脑能访问互联网,打开 HTML 文件时会自动从阿里云 CDN 加载字体**,无需任何安装。

**注意事项:**
- 第一次打开需要几秒钟加载字体(后续浏览器会缓存)
- 如果在内网/无网环境打开,会自动回退到系统字体(苹方/微软雅黑)
- 如果看到字体回退,说明 CDN 访问失败,需要检查网络或本地安装字体

### 方式 2:本地安装(推荐,离线也能用)

如果希望离线环境也能看到正确字体,或者希望导出 PDF 时字体加载更快,建议本地安装。

**Windows 安装步骤:**

1. 访问阿里巴巴字体官网:https://www.alibabafonts.com/
2. 下载"阿里巴巴普惠体 3.0"安装包(建议下载完整版 11 个字重)
3. 解压后,选中所有 `.ttf` 或 `.otf` 文件
4. 右键 → "为所有用户安装"(需要管理员权限)
5. 重启浏览器,打开 HTML 模板,字体会自动生效

**Mac 安装步骤:**

1. 从 https://www.alibabafonts.com/ 下载字体包
2. 双击 `.ttf` 文件 → 点击"安装字体"
3. 或者直接把字体文件拖到 Font Book(字体册)应用里
4. 重启浏览器

## 如何确认字体生效

打开 HTML 模板后,观察标题"乳品研发创新"等中文字,对比下面两种情况:

- **阿里普惠体生效:** 字形圆润、饱满,笔画粗细均匀,和原 FBIF 议程 PDF 一致
- **回退到系统字体:** 字形细硬一些,和原议程有明显差异

也可以按 F12 打开开发者工具 → 选中某个中文 → 查看 Computed 字体,如果显示 `Alibaba PuHuiTi 3.0` 就是成功生效。

## 常见问题

**Q:装完字体重启浏览器还是没变化?**
A:清一下浏览器缓存,或强制刷新(Ctrl+Shift+R)。

**Q:公司电脑没有管理员权限装不了?**
A:联网用 CDN 方式就行,不用安装。

**Q:导出 PDF 时字体丢失?**
A:Chrome 导出 PDF 会把字体嵌入 PDF 文件,所以 PDF 本身不依赖字体。但导出前要确保字体已经加载完成(等页面完全显示正确字体再打印)。
