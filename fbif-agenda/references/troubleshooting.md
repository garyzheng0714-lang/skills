# FBIF2026 议程模板 — 常见问题排查

## Q1: 页面打开空白或排版全乱

**原因**: HTML 中的 JavaScript 数据被改坏（多了/少了引号、逗号、括号）

**排查步骤**:
1. 在 Chrome 中按 F12 打开开发者工具 → Console 面板
2. 查看报错信息，通常会指出行号
3. 回到编辑器检查该行附近的 JSON 语法

**常见语法错误**:
- 漏掉逗号：`{ name: '张三' title: 'CEO' }` → 应为 `{ name: '张三', title: 'CEO' }`
- 多余逗号：`[item1, item2, ]` → 末尾不应有多余逗号（虽然 JS 允许，但建议统一）
- 引号不匹配：`title: '含有'单引号的文字'` → 用反斜杠转义 `\'` 或改用双引号
- 括号不配对：删除条目时只删了内容没删对应的 `{}`

**恢复方法**: 按 Ctrl/Cmd+Z 撤销，或从备份恢复。

## Q2: 打印 PDF 颜色丢失（全黑白）

**原因**: 打印对话框没勾选"背景图形"

**解决**:
- Chrome: 打印 → 更多设置 → 勾选 **背景图形**
- Edge: 打印 → 更多设置 → 勾选 **背景图形**
- 英文版: 勾选 **Print backgrounds** 或 **Background graphics**

## Q3: 字体看起来像宋体/雅黑

**原因**: 阿里巴巴普惠体未加载

**排查**:
1. 检查是否联网（模板内置 CDN 引入）
2. 点击右上角"字体诊断"按钮检查字体加载状态
3. 按 F12 → 选中中文文字 → Computed → 查看实际渲染字体

**解决**:
- 联网环境：刷新页面等待 CDN 加载
- 离线环境：本地安装阿里巴巴普惠体 3.0（Regular/Medium/Bold 三个字重）
- 下载地址：https://www.alibabafonts.com/
- 安装后需**重启浏览器**（不是刷新页面）

## Q4: 某页内容太多被压缩

**原因**: 自适应缩放触发（最多缩到 70%）

**解决方案**（按优先级）:
1. 精简描述文字（缩短 desc 字段）
2. 减少嘉宾数量或合并话题
3. 手动设置缩放比例：将该页的 `scaleOverride: null` 改为具体值（如 `scaleOverride: 0.85`）
4. 点击右上角"重新计算缩放"按钮

## Q5: 修改后不确定是否改对

**验证步骤**:
1. 保存 HTML（Ctrl/Cmd+S）
2. 回到 Chrome 按 F5 刷新
3. 检查右上角工具栏：
   - 总页数应为 33
   - 如果显示正常数字，说明改对了
   - 如果页面空白，说明有语法错误

## Q6: 底部导航点击跳转不对

**排查**: 检查 `FOOTER_TABS` 中的 `key` 字段是否对应正确的 forumKey，以及 `FULL_STRUCTURE` 中的页面顺序是否正确。

## Q7: 新增论坛后页面数不对

**注意**: 增删整个论坛需要同时修改：
1. `FORUM_CONFIG` — 添加论坛配置
2. `FOOTER_TABS` — 添加底部导航
3. `FULL_STRUCTURE` — 添加分隔页和议程页条目
4. `PAGES` — 添加议程数据
5. `GUEST_LISTS` — 添加嘉宾名单
6. CSS 样式 — 添加论坛主题色

这属于结构性改动，建议由熟悉模板的人操作。

## Q8: 工具栏按钮说明

| 按钮 | 功能 |
|---|---|
| 总页数 | 当前渲染页数，应为 33 |
| 自动缩放 X 页 | 触发自动缩小的议程页数 |
| 手动微调 X 页 | 设置了 scaleOverride 的页数 |
| 打印/导出全部 PDF | 一键打印/导出 |
| 重新计算缩放 | 修改内容后重新计算排版 |
| 字体诊断 | 检查阿里普惠体是否加载 |

## 备份建议

- 定稿版永久保留
- 每次结构性改动前复制一份
- 命名规则：`FBIF2026议程模板_日期_改动说明.html`
- 大改动后导出 PDF 归档
